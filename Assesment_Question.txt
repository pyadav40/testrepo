Explain custom hooks.
	Custom hooks are reusable functions that encapsulate stateful React logic and can internally use other hooks. They help avoid code duplication by extracting common behavior such as data fetching, authentication, authorization, subscriptions, or form management. Unlike components, custom hooks do not return JSX; they return values, state, or functions that can be consumed by multiple components while still following React's Rules of Hooks.

State Management
	State management is the strategy of managing application data, including where state is stored, how it is updated, and how it is shared across components. Good state management ensures predictable UI updates, reduces prop drilling, and improves maintainability. In React, we typically start with local state using useState or useReducer, move to Context for shared state, and use libraries like Redux Toolkit or Zustand when global state becomes complex. For server-side data, I generally prefer TanStack Query because server state and UI state should be managed differently.
